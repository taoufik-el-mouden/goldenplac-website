# Goldenplac Website

Professional responsive website for **Goldenplac SL**, a company specialized in Pladur and interior renovations in Madrid.

## Live Demo

https://goldenplac.page.gd/?i=1

## Features

- Responsive modern website
- Services and project showcase
- Before & After gallery
- Interactive renovation calculator
- Customer testimonials section
- Admin panel for local content management
- LocalStorage-based data persistence
- Responsive design for desktop, tablet and mobile

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- SVG
- LocalStorage API
- Web Crypto API
- Responsive Web Design

## Run Locally

This is a static front-end project. You can run it with any local HTTP server, for example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Note

The admin interface uses browser-side LocalStorage and client-side authentication logic. It is suitable for a static/demo project, but it should not be considered a secure production authentication system without a server-side backend.
